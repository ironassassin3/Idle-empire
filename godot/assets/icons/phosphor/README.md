# Phosphor Icons (MIT)

Stroke icons from [Phosphor Icons](https://phosphoricons.com/) — `regular` weight SVGs.

| File | Used on |
|------|---------|
| `gear.svg` | Config header button |
| `buildings.svg` | Bldgs tab |
| `trend-up.svg` | Upgrs tab |
| `users-three.svg` | Mgrs tab |
| `map-pin.svg` | Turf tab + Territory subtab |
| `chart-bar.svg` | Stats tab |
| `sword.svg` | Rivals subtab |
| `users.svg` | Crew subtab |
| `briefcase.svg` | Ops subtab |

Wiring: `GameIcons` + `GameTheme.apply_tab_nav_icon()` / `apply_gear_icon_button()`.  
Tint: theme `icon_*_color` overrides (gold ink palette).
